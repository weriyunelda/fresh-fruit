FreshFruit adalah website e-commerce untuk penjualan buah-buahan segar secara online. Website ini dirancang untuk memudahkan pelanggan melihat produk, memilih buah, melakukan pemesanan, dan memantau status pesanan.

Project ini dikembangkan menggunakan arsitektur mikroservices dengan pemisahan forntend dan backend agar setiap layanan dapat dikembangkan dan dikelola secara terpisah dengan Frontend : Aldi Nurarifin (24260001) dan Backend  : Weri Yunelda (24260038)

Fitur utama  
-Registrasi dan login pengguna   
-Katalog dan detail produk buah  
-Pencarian dan kategori produk  
-Keranjang belanja  
-Checkout dan pemesanan  
-Informasi pembayaran dan status pesanan  
-Dashboard admin untuk mengelola produk, stok, dan pesanan
